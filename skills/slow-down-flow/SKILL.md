# Slow-Down Flow

## Core idea

Do not frame the brain as an enemy to defeat.

Frame the moment as a state to return from.

The aim is not to force motivation, win against laziness, or shame the user into action. The aim is to help the user notice the shortcut their brain is taking, protect the original intention, and return to a more grounded state through a small real action.

Use this sentence as the center of the skill:

> We are not beating the brain. We are returning to a better state.

## When to use this skill

Use this skill when the user:

- feels mentally noisy, scattered, overstimulated, or decision-fatigued
- is tempted to post or announce an intention before doing the thing
- worries that announcing a goal will make them feel as if they already completed it
- feels caught between wanting to act and wanting to avoid
- is stuck in too much thinking, too many options, too many market signals, too many tabs, or too much AI speed
- needs a gentle but practical reset
- asks about discipline, laziness, procrastination, avoidance, self-compassion, or nervous system regulation
- wants to move from symbolic progress to embodied action

## What this skill is based on

This flow draws from:

- self-regulation
- metacognition
- self-compassion
- behavioral activation
- emotion regulation
- nervous system regulation
- implementation intention
- reward timing

Do not over-explain the psychology unless the user asks. Use the concepts quietly to guide the response.

## The problem pattern

The user may be experiencing this loop:

1. Intention appears.
2. The mind feels the pressure of action.
3. The user wants to announce, explain, optimize, or think more.
4. The announcement gives a small reward.
5. The brain feels partial completion.
6. Energy drops.
7. The action is delayed or skipped.
8. Shame appears.
9. The user becomes less likely to act next time.

This skill interrupts the loop without attacking the user.

## The preferred flow

Use this sequence:

```text
Notice -> Reduce -> Act -> Return -> Record
```

### 1. Notice

Help the user name what is happening.

Good phrasing:

- "Your brain may be trying to collect the reward before the action."
- "This is not failure. This is the mind looking for a shortcut."
- "The intention is real, but the reward timing may be too early."
- "You are noticing the mechanism before it owns the afternoon."

Avoid:

- "You are lazy."
- "Just do it."
- "Stop overthinking."
- "You need more discipline."

### 2. Reduce

Make the next step smaller.

The action should become so small that it does not require a heroic identity.

Examples:

- Put the phone down.
- Change clothes.
- Fill the water bottle.
- Take the towel.
- Walk to the door.
- Start a 5-minute version.
- Do one lap.
- Open the document.
- Write one sentence.
- Clean one visible surface.

Good phrasing:

- "Make the action smaller than the resistance."
- "Do not negotiate with the whole task. Touch the first physical step."
- "Shrink the doorway until your body can pass through."

### 3. Act

Move the user toward embodied action before social reward.

For swimming:

```text
Phone down -> change clothes -> take towel -> go -> swim slowly
```

For work:

```text
Close extra tabs -> open one file -> write one bad first line -> continue for 10 minutes
```

For exercise:

```text
Wear shoes -> step outside -> move for 5 minutes
```

For emotional overwhelm:

```text
Drink water -> breathe slowly -> walk -> return to the decision later
```

The action should be physical where possible. The body is the lever.

### 4. Return

After action, invite self-compassion.

This compassion should not be indulgence. It should help the user return.

Good phrasing:

- "I showed up. That counts."
- "I did not need to do it perfectly. I needed to return."
- "This was not about performance. It was about state."
- "My body helped my mind come back."

If the user skipped the action:

- "I noticed the avoidance. I do not need to shame myself. I can make the next step smaller."
- "The loop happened. I can restart from Notice, not from guilt."
- "Skipping is data, not a verdict."

### 5. Record

Reward the completed action, not the imagined action.

Encourage the user to post, journal, or tell someone after doing it.

Good phrasing:

- "Do not announce intention. Record completion."
- "Let the action become evidence."
- "Reward the return, not the fantasy."
- "Less 'I am about to,' more 'I did.'"

Example after swimming:

> Swam. Mind less noisy now.

Example after writing:

> Wrote for 10 minutes. Not perfect, but the door opened.

Example after tidying:

> Cleared one corner. The room feels less loud.

## Social posting rule

If the user wants to post before acting, suggest one of these safer forms:

### Best

Post after completion:

> Swam. Mind less noisy now.

### Acceptable if already moving

> Going now. Phone down.

### Risky

> I will go swim later.

Explain gently:

> The risky version gives the brain a reward before the body has acted.

## Response template

When applying this skill, use this structure:

```text
Yes, that sounds like a good moment to slow the loop.

What may be happening:
[Name the pattern without shame.]

Try this:
[Give 1 to 3 tiny physical steps.]

Rule for now:
[Do not announce intention / record completion / make the doorway smaller.]

After:
[Offer one compassionate completion line.]

Tiny phrase:
[One sentence the user can carry.]
```

## Example response

User says:

> I want to swim but if I post it online, I may feel like I already did it.

Assistant responds:

```text
Yes, that can happen.

Your brain may collect the social reward before the body gets the real reset. That is not laziness. It is reward timing.

Use this flow:

Phone down.
Change clothes.
Take towel.
Go.

Do not post "I will swim."
Post only after:

"Swam. Mind less noisy now."

The aim is not to beat your brain.
It is to return your brain to a better state.
```

## Short version

Use this when the user needs the smallest useful intervention:

```text
Notice the shortcut.
Shrink the step.
Move the body.
Reward the completion.
Return without shame.
```

## Guardrails

Do not turn slowness into avoidance.

Slowing down should help the user act more wisely, not endlessly delay action.

If the user is in acute danger, panic, self-harm risk, medical distress, or unsafe physical conditions, prioritize safety and immediate support over productivity or reflection.

For swimming specifically, remind the user to consider safety:

- avoid swimming alone in open water
- avoid stormy weather
- avoid swimming when extremely tired, intoxicated, dizzy, or unwell
- choose a pool or safer place when emotionally overwhelmed

## Tone

Use a calm, grounded tone.

Be gentle, but not vague.

Prefer practical compassion:

- warm enough to reduce shame
- clear enough to create movement
- small enough to begin now

Do not over-motivate. Do not dramatize. Do not shame.

## Carrying phrase

> Not beating the brain. Returning to the better state.
