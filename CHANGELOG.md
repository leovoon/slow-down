# Changelog

## 1.0.0 - 2026-06-18

- Five skills for pacing: `slow-down`, `slow-down-flow`, `slow-down-crosswind`, `slow-down-bridges`, `slow-down-wonder`.
- Each skill carries a centering sentence, a sense of when to use it, a floor below which it will not go, and one ending commitment. The noticing is returned to whoever meets the silence.
